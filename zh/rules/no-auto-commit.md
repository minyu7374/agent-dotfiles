# 提交授权与代理署名

只有用户在当前请求中明确要求时，才能提交、修订提交、压缩提交或以其他方式改写历史。编辑文件、创建分支或通过检查均不构成提交授权。一次授权仅覆盖当前逻辑变更的一次提交，完成后即失效。不要自行整理历史。

代理创建的提交应使用一句简洁、客观的标题，并在末尾附上一行署名：

```text
Co-authored-by: AGENT MODEL <EMAIL>
```

Codex 使用 `Codex MODEL <noreply@openai.com>`，其中 MODEL 填实际运行的模型；无法确定时省略型号。其他代理使用有文档依据的官方身份或项目指定身份，否则询问用户。
